# HR Analytics Dashboard

## 📊 Project Overview

This project presents an **interactive HR Analytics Dashboard** developed using **Tableau**. The dashboard helps analyze key workforce metrics and provides insights into employee attrition, demographics, job satisfaction, education, age distribution, and gender-based attrition.

The goal of this project is to transform raw HR data into an interactive and visually appealing dashboard that helps identify important workforce trends and supports data-driven decision-making.

## 📈 Dashboard Analysis

The dashboard includes the following interactive visualizations:

### 1. Attrition by Department

Analyzes employee attrition across different departments, helping identify departments with higher employee turnover.

### 2. Employee Distribution by Age

Visualizes the distribution of employees across different age groups and highlights the workforce's demographic structure.

### 3. Job Satisfaction Rating

Displays job satisfaction levels across different job roles using a heatmap, making it easier to identify patterns and compare employee satisfaction.

### 4. Attrition by Education Field

Shows attrition across different educational backgrounds, including Life Sciences, Medical, Marketing, Technical Degree, Human Resources, and other fields.

### 5. Attrition by Gender

Compares employee attrition between male and female employees.

### 6. Attrition by Gender Across Age Groups

Analyzes how attrition varies across different age groups and genders, providing deeper demographic insights.

### 7. Interactive Education Filter

The dashboard includes an interactive education filter that allows users to dynamically explore workforce and attrition data based on different education levels.

## 🔍 Key Insights

* The organization has **1,470 employees**, with **237 employees leaving**, resulting in an overall attrition rate of **16.12%**.
* The largest employee population is concentrated around the **25–34 age group**.
* Attrition varies significantly across different departments.
* **Life Sciences** has the highest attrition among the education fields displayed.
* Job satisfaction levels differ across job roles.
* Male employees account for a higher number of attrition cases compared to female employees.
* The dashboard enables users to explore HR trends interactively using the education filter.
